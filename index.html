Explainable Transfer Learning-Based Deep Convolutional Neural Network for Cultivar-Specific Amrapali Mango Fruit Disease Classification

Department of Computer Science & Engineering • Daffodil International University

Developed a tailored, cultivar-specific deep learning classification framework for 7 major Amrapali mango fruit diseases. Evaluated multiple pre-trained CNN backbones using transfer learning and fine-tuning strategies. Integrated Gradient-weighted Class Activation Mapping (Grad-CAM) to provide transparent visual explanations verifying model attention matches true pathological symptoms.

Methodology: CNNs, Transfer Learning, Grad-CAM (XAI), Cultivar-Specific Analysis
